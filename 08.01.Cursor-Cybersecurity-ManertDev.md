## What we built

**ManertDev** (built as *SentinelDev* on the day) is an AI-powered, terminal-native security helper you run **while you're still developing** — "Denuvo for your app in development".

You point it at a codebase and ask in plain English ("are there exposed endpoints?", "check my secrets"). It finds exposure risks with file + line evidence and **proposes** fixes — it never modifies your code on its own. Patches are only produced when you explicitly ask, ready to paste into Cursor.

### What it does

- **Endpoint exposure** — finds public / admin / debug routes with file:line evidence
- **Secrets & env** — detects keys, tokens, committed `.env` files, weak names
- **System entrances** — maps admin panels, debug routes, Swagger, CORS, open ports
- **Database exposure** — flags DB routes, raw queries and injection-prone sinks
- **Key scramble** — suggests key rename and rotation patterns
- **IAM / PDF reasoning** — "who can do what / what's overly permissive?" over policy docs and PDFs, with line citations (built for the IBM Challenge track)
- **Supply-chain scan** — checks dependencies for malicious packages via Ossprey
- **Fix logs** — every finding is logged to Supabase PostgreSQL with project and problem tracking

Every report has the same shape: Summary → Findings (Critical / High / Medium / Low / Info) → Evidence → Proposed Fixes → Optional Patch.

### How it's put together

- **CLI** (`manert`) — runs from any directory, interactive REPL with natural-language keyword routing, plus one-shot `scan` / `ask` commands
- **Web dashboard** — Next.js 15 + React 19 UI, opened with `manert dashboard` using the current directory as the scan root; copy-the-fix-prompt button for Cursor
- **API** — `/api/chat`, `/api/scan`, `/api/pdf`, `/api/fix-logs`
- **Local-first scanners** — work offline with no model; AI is layered on top
- **Models** — NVIDIA Nemotron for analysis, with resilient OpenRouter fallbacks
- **Modal** — cloud workers for heavy scans and hosted model asks (`manert modal`)
- **Safety contract** — no hallucinated endpoints, keys or IAM principals; uncertainty is stated explicitly
